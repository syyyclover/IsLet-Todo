# IsLet-Todo 0.4.0 Preview 4

Windows 11 x64 验证版。当前不标记为完整 v1。

修复中文输入法组合输入导致编辑页误收起，以及托盘“退出”被系统关闭拦截逻辑阻止的问题。preview.2 含退出缺陷，应更新至此版本。

本次修订重新生成交付包、更新 README 与包内使用说明，并核对实际程序版本；修复 CI 动画测试对构建机系统设置的隐含依赖，保留正常动画与减少动画两条验证路径。不是对首次失败构建的发布成功声明。

- 托盘常驻，不出现在任务栏或 Alt+Tab，系统关闭仅收起。
- 深色托盘菜单仅保留退出、打开备份文件目录；图标约 7 KiB。
- 日程、归档、设置支持鼠标移入直接切换，草稿后台保留。
- 日程时间滚轮、通知点击定位、附件独立副本、完成归档后清理副本。

`setup-x64.exe` 为普通用户权限安装包，安装在 `%LOCALAPPDATA%\Programs\IsLet-Todo`，不会删除 `%LOCALAPPDATA%\TaskIsland` 下的数据与备份。`portable-x64.zip` 解压后运行 TaskIsland.exe；数据同样保存在当前用户的 TaskIsland 目录。更新、安装或卸载前请通过托盘退出，保留好未保存内容。

安装包与便携程序尚未签名。完整安装卸载、干净机器、多 DPI、多显示器、全屏、Explorer 重启、完整附件异常矩阵及 8 小时运行仍待验收。当前展开目录约 206 MiB，超过 200 MiB 目标；未提高原性能预算。

SHA256SUMS.txt 提供发布附件的校验值。项目仓库保留软件源码和开发记录；测试源码按用户要求移除，历史记录仍保留，发布附件只提供当前验证版。

preview.4 增加控件级悬停提示拦截，覆盖模板生成的提示。运行目录和交付包保持单一当前版本；本地生成缓存与旧产物清理记录见 docs/validation/TOOLTIPS-2026-10-30.md。
