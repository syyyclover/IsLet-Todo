# TaskIsland v1 开发目标与路线

日期：2026-10-28。需求来源：[`IsLet_Todo.md`](../IsLet_Todo.md)。本文将既定需求分解为开发阶段，不替代原文的产品与技术规则。

## 目标与范围

在 Windows 11 x64 上交付低打扰的顶部日程岛，完整支持任务、时间、归档恢复、附件副本、系统通知和本地持久化。主要操作留在岛内，用户数据可靠保存，普通用户无需开发环境即可运行发布包。

首版不增加云同步、账号、重复任务、子任务、标签、团队协作、AI、内置视频播放器、自动更新或跨平台支持。Windows 10、ARM64 不属于首版正式验收范围。

技术方向沿用基线的 C# / .NET 10 / WPF。执行路线采用原文的风险优先顺序：完整功能直接并行铺开容易推迟发现窗口、通知和发布阻断；先做业务再补系统集成也无法尽早验证资源预算。因此先验证系统骨架，再逐层实现业务。

## 规划模块与目录

以下模块和对应测试均已创建；附件和完整系统能力仍按后续阶段实现。

| 路径 | 职责 |
|---|---|
| `src/TaskIsland.Domain/` | 任务模型、排序、标题文本元素及时间规则 |
| `src/TaskIsland.Application/` | 任务、附件、调度用例与外部能力接口 |
| `src/TaskIsland.Infrastructure/` | SQLite、迁移、文件副本、清理队列与日志 |
| `src/TaskIsland.WindowsIntegration/` | 托盘、通知、单实例、IPC、自启动、显示器和全屏检测 |
| `src/TaskIsland.Presentation/` | WPF 入口、依赖装配、状态机、ViewModel、界面与动画 |
| `tests/TaskIsland.Domain.Tests/` | 模拟时间、排序与 Unicode 规则测试 |
| `tests/TaskIsland.Application.Tests/` | 用例、调度、提醒版本和失败路径测试 |
| `tests/TaskIsland.Infrastructure.Tests/` | SQLite、迁移、附件和文件清理集成测试 |
| `docs/validation/` | 后续产生的 Windows 验收及性能实测记录 |

依赖方向：Domain 不依赖 UI 或平台；Application 依赖 Domain 并定义端口；Infrastructure 和 WindowsIntegration 实现端口；Presentation 装配并调用用例。接口以基线第 3.3 节为准，任务、附件和调度职责拆开。

## 执行与记录方式

每阶段开始前，将该阶段细化为可独立验证的小任务，再实施。涉及业务规则时执行失败测试 → 最小实现 → 测试通过；阶段结束记录执行命令、环境、结果、人工验收与未验证项。当前构建与测试命令见 README，M1 细化步骤见 `docs/superpowers/plans/2026-10-28-m1-windows-shell.md`。

当前主要风险：未打包通知注册与激活、自包含运行依赖和发布大小、WPF 透明窗口动画资源占用、焦点与多显示器定位、提醒与数据库之间的崩溃窗口、附件文件系统与数据库一致性。分别在 M1、M2/M3、M4 提前验证，不能留到最终交付才发现。
