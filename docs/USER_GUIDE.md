IsLet-Todo 使用说明

适用系统：Windows 11 x64。当前为预览版。

安装版：运行 setup-x64.exe，以普通用户权限安装。
便携版：解压整个 ZIP，运行 TaskIsland.exe；不要只复制 EXE。
更新前请保存内容并通过托盘退出旧版，避免单实例转发到旧进程。

鼠标移入顶部岛即可展开，离开任意页面则回到日程列表并收起。
鼠标移入“日程 / 归档 / 设置”页签即可切换，无需点击。
点击“添加日程”输入内容，用滚轮选择日期、小时和分钟。
未保存草稿在切页和收起时保留，可通过“添加日程”继续。

将文件拖到具体日程行添加附件，软件保存独立副本。
完成或归档日程时清理应用副本，来源文件不会被删除。
删除附件或归档记录等安全操作需要双击相同按钮确认。

软件不显示在任务栏和 Alt+Tab 中；Alt+F4 只收起。
托盘左键展开岛，右键仅有“退出”和“打开备份文件目录”。

日程、附件和设置保存在 %LOCALAPPDATA%\TaskIsland\。
backups 文件夹目前保存数据库迁移前备份，可能为空，并非定时备份。
手动备份请退出软件后复制整个 TaskIsland 数据目录。
卸载不会删除该数据目录。
