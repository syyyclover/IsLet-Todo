# 托盘常驻与发布目录整理

2026-10-29 用户修订：不出现在任务栏与 Alt+Tab，只通过托盘退出；托盘右键只保留“退出”“打开备份文件目录”。沿用深色、浅绿色及统一线性图形，使用小型多尺寸 ICO，不引入图片模型输出或额外图形库。

执行顺序：

1. 原生窗口样式与关闭消息建立失败测试，设置 WS_EX_TOOLWINDOW 并移除 WS_EX_APPWINDOW；系统窗口关闭仅收起，托盘退出保留复制等待/取消流程。
2. 两项菜单共用轻量深色渲染；备份目录通过原生默认程序 API 打开 `%LOCALAPPDATA%\TaskIsland\backups`，不存在时创建，失败在岛内显示。
3. 执行测试、Release 发布和自包含安装包生成；如验收未全部完成，明确标为验证版本，不宣称完整产品发布。
4. 先清点再清理：移除旧发布目录和临时诊断/截图/测试运行产物，保留最新软件与安装包；源码、自动化测试、必要文档、用户数据与备份不作为废弃测试产物删除。远程先检查 Release/产物及分支是否合并，保持主分支为最新代码，不改写历史。

现存未通过项：M4 图片/异常矩阵、M5 多 DPI/多显示器/全屏/Explorer 重启/干净机器及性能门槛。安装、卸载和原生 Alt+Tab 体验需另行实际验证。
