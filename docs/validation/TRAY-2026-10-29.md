# 托盘常驻、打包与清理记录

2026-10-29，Windows 11 x64；.NET SDK 10.0.403，Inno Setup 6.7.4。

## 实现与证据

- 原生 HWND 设置 WS_EX_TOOLWINDOW、移除 WS_EX_APPWINDOW，保留分层透明与输入行为；WM_CLOSE 仅回到日程并收起，托盘退出仍走复制保护与正常资源释放。
- 修改前原生样式和 WM_CLOSE 两项测试均失败，修改后两项通过。
- 托盘右键仅有退出与备份目录；左键展开岛。菜单深色、浅绿色选中态，与岛内风格一致。多尺寸 ICO 7,157 字节，通过 16/32px 加载和大小测试，无新图形依赖。
- 备份目录 `%LOCALAPPDATA%\TaskIsland\backups` 不存在时创建，直接通过 UseShellExecute 打开；无拼接 shell 命令。
- 用户实测答复“都正常，观感合适”：任务栏/Alt+Tab 隐藏、Alt+F4 不退出、菜单两项及打开备份目录、视觉均通过。

## 执行

- `dotnet restore TaskIsland.slnx --locked-mode` 成功。
- 首轮完整测试遇到原有动画反向测试失败；WPF 测试窗口仍接受桌面真实鼠标事件，可能干扰合成事件。测试宿主增加仅测试使用的 HTTRANSPARENT hook，避免真实指针改变状态；产品仍正常接收输入。修订后全套 Release 196 项通过，无跳过：Domain 19、Application 20、Infrastructure 56、WindowsIntegration 25、Presentation 76。
