# 双击确认、全页面收起与归档副本清理

日期：2026-10-29。用户明确修订：安全二次确认改双击；所有页面离开即收起；拖入但不释放而移出也收起；完成与归档合并，归档后清理独立副本且归档页不显示附件。

## 实现

- 新增共用 DoubleConfirmButton，首次激活只标记，Windows 双击时间范围内相同目标第二次激活才执行。超时、失焦、隐藏、卸载、数据上下文或参数变化会撤销首击状态；键盘与辅助技术连续激活两次也可确认。删除、清空归档、移除附件、放弃草稿使用此控件，不再展示第二个确认面板。
- 有草稿时返回/取消/页签需双击，普通无改动导航仍为单击。保存和时间选值提交不是安全二次确认，保留正常提交方式；复制中退出的等待/取消选择继续保留。
- 所有页面离开时切回日程列表并立即收起，再进入始终打开日程列表。编辑草稿在后台保留，通过添加入口继续；点击另一条日程不会覆盖未保存草稿。外部拖动期间每 16ms 检查系统鼠标位置以补偿 OLE 拖动漏发的离开消息，拖动结束即停止检查。高亮使用不参与命中和布局的 Adorner，只在目标行变化时更新。
- 活跃日程行仅一个“完成并归档”入口，归档列表移除附件入口。
- 完成、手动及自动归档在同一 SQLite 事务内移除附件记录并登记管理副本清理队列。随后立即尝试实际删除副本，后台低频校准继续重试占用文件。来源文件不删除，恢复任务不恢复已清理附件。新规则应用于新发生的归档动作，不进行历史附件一次性批量销毁。

附件由 FileStream 写入应用管理目录下的独立副本，不是快捷方式，也不依赖源文件路径。删除只通过路径边界校验后的副本清理服务。

## 验证

Release 全套测试 189 项通过，无跳过：Domain 19、Application 20、Infrastructure 56、WindowsIntegration 23、Presentation 71。新增双击/超时/控件回收/自动化激活测试；全部页面收起后默认日程页测试、后台草稿保护测试；三种归档原因的附件记录/清理意图原子变更、事务失败回滚、来源不变、占用后重试及恢复不带回附件测试。新增归档测试和页面状态测试均先观察失败再修复。

前一验证版已发布启动。用户实测发现外部拖动移出仍未可靠收起、同一行横向拖动边框闪动，并要求再次展开默认日程页；本轮据此修订。本轮 Release 189 项通过，后台草稿保护测试移除保护后实测失败、恢复后通过；自包含发布至暂存目录成功，退出旧版后复制到原发布路径并启动（PID 4272）。用户已实测确认新版同一行横向拖动边框稳定、不释放拖出后能收起。编辑/归档/设置页离开后默认日程列表及后台草稿继续仍待用户确认。真实鼠标双击手感、外部资源管理器拖动取消的消息时序及文件占用行为仍需联合验收；不能用 WPF 状态机测试替代这些实测。性能预算与既有未通过项保留。
