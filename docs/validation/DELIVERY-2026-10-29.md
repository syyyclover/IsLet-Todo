# 0.4.0-preview.2 交付修订

用户反馈软件包、安装包及 README 未更新。核查：preview.1 只有本地交付包，首次 GitHub Actions 构建失败，Release 未发布；README 仍混有旧托盘入口和旧 M2 状态。

本轮范围：读取并修复远程失败测试；明确 README 当前行为、数据目录、下载入口和未完成验收；软件版本、安装器与便携包版本一致；打包时核对实际程序集版本并附使用说明；成功上传后再确认交付。

已增加 TRX 失败注解，诊断构建 run 40851976159 公开报告四项动画中间态断言失败：CollapsingKeepsPageVisibleUntilContentHasFaded、PeerPagesKeepTabsAndSlideWithoutBackHierarchy、HoverTabsSwitchImmediatelyAndLatestPageWinsDuringSlides、PointerStartsOpenAndCloseImmediatelyWithoutChangingMotionDuration。共同表现为动画直接完成；测试原先隐含依赖系统 ClientAreaAnimation 开关。

窗口通过内部可注入的系统动画策略进行测试，正式构造仍读取 Windows ClientAreaAnimation。WPF 测试明确启用动画路径，新增关闭系统动画时即时呈现最终状态的测试；不改系统设置、不跳过测试、不修改产品动画时长。

打包前读取 TaskIsland.dll ProductVersion 并与交付版本比较；使用 0.0.0 请求包装 preview.1 程序时已实测拒绝。安装器源目录显式传入，便携与安装版均附 README.txt 使用说明，校验清单只包含本次两个包。发布命令显式指定 csproj，避免 WPF 临时项目文件干扰目录推断。

完整测试、重新构建与附件校验结果在执行后记录。原有托盘与开合交互不因发布流程修订而调整。
