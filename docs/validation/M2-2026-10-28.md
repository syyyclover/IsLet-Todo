# M2 任务与持久化验证

日期：2026-10-28。分支：`feat/m2-task-persistence`，起点 `87952a1`。用户确认动画流畅并要求继续开发后推进本阶段；M1 通知点击、多 DPI、干净机器和性能门槛仍未通过。

## 已实现范围

- Domain：独立结束/归档时间、续期不累计且不改变提醒版本、完成/归档/恢复、稳定排序、200 文本元素标题及 9 文本元素摘要。
- SQLite schema v2：UTC Unix 毫秒、WAL、外键、统一后台串行事务；迁移前一致性备份，失败回滚，损坏或未知版本不覆盖重建。
- 用例与调度：任务变更、单任务置顶、分页归档、启动校准、下一事件单次定时器和 60 秒校准；系统恢复/时间变更接入校准请求。空闲校准无数据库写入，退出排空已接受写入。
- 岛内添加、编辑、完成、置顶、续期、归档和恢复；保存失败保留输入，未保存离开在岛内确认；列表虚拟化，原有开合动画回归保留。
- 新建界面目前仅创建无结束时间任务，编辑保留已有结束时间。结束时间 API 和规则已测试，滚轮选择、正式通知发送与重试、删除确认、自启动和全屏隐藏留在 M3；附件留在 M4。位置与动画设置尚未持久化。

## 自动验证

实际执行锁定依赖 restore、Release/Debug build、Release 全套 test 和自包含 publish。Release 与 Debug 构建均为 0 警告、0 错误；74 项测试通过，无跳过。

| 测试程序集 | 通过数 |
|---|---:|
| Domain | 19 |
| Application | 10 |
| Infrastructure | 21 |
| WindowsIntegration | 4 |
| Presentation | 20 |

业务与集成测试先观察失败再实现通过。覆盖时间前后跳变、提醒版本去重、过归档时间不补提醒、事务失败、并发写入、重启恢复、迁移备份与失败、损坏及未知版本保留、后台 I/O 和退出排空。时间测试采用官方 FakeTimeProvider，不等待真实时间。测试数据使用独立临时目录，未向用户数据库注入演示任务。

独立代码审查发现三个编辑边界：重复添加覆盖草稿、保存中输入的新文字丢失、忙碌时后台变更未刷新。为三个问题新增失败测试，再修复通过；另以真实 WPF 窗口测试编辑、保存和未保存离开确认。12 项原有动画测试继续通过。

主要命令（均已执行）：

```powershell
./.tools/dotnet/dotnet restore TaskIsland.slnx --locked-mode
./.tools/dotnet/dotnet test TaskIsland.slnx -c Release --no-restore
./.tools/dotnet/dotnet build TaskIsland.slnx -c Release --no-restore
./.tools/dotnet/dotnet build TaskIsland.slnx -c Debug --no-restore
./.tools/dotnet/dotnet publish src/TaskIsland.Presentation -c Release -r win-x64 --self-contained true --no-restore -o artifacts/publish/m2-win-x64
./scripts/Smoke.ps1 -PublishDirectory artifacts/publish/m2-win-x64
```

Smoke 在当前 Windows 开发机通过主窗口出现、第二实例转发、正常退出检查；首次窗口句柄出现约 4787ms，最终复测约 1610ms，这些值不代表冷启动或可交互时间验收。自包含目录 205.52 MiB，超过 200 MiB 目标。旧 M1 资源测量不能当作 M2 性能结果。

## 依赖与实现依据

实际锁定稳定包 Microsoft.Data.Sqlite 10.0.14；测试使用 Microsoft.Extensions.TimeProvider.Testing 10.11.0。SQLite 的异步 API 实际同步执行，因此串行数据库回调整体放到后台线程，见 [官方异步限制](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/async)。备份与事务分别参照 [在线备份](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/backup) 和 [事务](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/transactions)。
