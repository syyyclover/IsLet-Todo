# 模板提示与目录清理

用户报告顶部日程岛内出现“Click to go forward, hold to see history”。源码未包含该文案，尚不能断言实际来源；现有 Button/TextBox 等样式不足以覆盖模板生成的控件。

新增测试模拟子控件自行开启该提示，旧实现失败。窗口实例监听仍失败，原因是 ToolTipOpening 为直接事件。最终在本应用进程中对 FrameworkElement、FrameworkContentElement 注册类处理器，阻止提示开启，不修改其他应用。该回归测试已通过；原场景仍待用户实测，不以合成事件替代来源验证。

清理范围：保留 src、scripts、installer、docs、项目/依赖锁文件、SDK/打包工具及 Git 历史；运行文件仅 artifacts/publish/current，交付包仅 artifacts/release 中的最新版本。清理旧发布、测试结果和 bin/obj 缓存；测试源码删除范围正在等待用户明确答复，未擅自删除。用户数据目录不在清理范围。

preview.4 的完整验证、发布和清理实际结果在完成后追加。
